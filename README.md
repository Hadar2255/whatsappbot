# שולי - בוט ווטסאפ חכם

בוט ווטסאפ בעברית עם AI, מבוסס על whatsapp-web.js ו-Gemini Flash.

## תכולה

- **רשימת קניות** - הוספה, הסרה, הצגה
- **ניהול משימות** - יצירה, סימון כבוצע, הצגה
- **משמרות עובדים** - הקצאה וצפייה
- **נוכחות** - כניסה/יציאה ודוחות
- **בקשות רפואיות** - רישום ומעקב

כל קבוצה מקבלת מסד נתונים (SQLite) משלה. הבוט מגיב רק כשמזכירים אותו "שולי".

---

## הוראות התקנה - Windows

### דרישות מוקדמות

1. **Node.js 18+** (LTS)
   - הורד מ: https://nodejs.org
   - בדוק: `node --version`

2. **Python 3.x** (נדרש ל-better-sqlite3)
   - הורד מ: https://www.python.org
   - בסימון ההתקנה: סמן ✓ "Add Python to PATH"

3. **כלי בנייה של Windows** (נדרש ל-better-sqlite3)
   - פתח PowerShell **כמנהל** והרץ:
   ```
   npm install --global windows-build-tools
   ```
   - או התקן **Visual Studio Build Tools** ידנית (כולל "Desktop development with C++")

### שלבי התקנה

```bash
# 1. שכפל את הפרויקט
git clone <repository-url>
cd whatsappbot

# 2. התקן תלויות
npm install

# 3. הגדר משתני סביבה
copy .env.example .env
```

פתח את קובץ `.env` בעורך טקסט והכנס את מפתח ה-API של Gemini.

### קבלת מפתח Gemini (חינמי)

1. היכנס ל: https://aistudio.google.com
2. לחץ על "Get API Key"
3. צור מפתח חדש
4. העתק אותו לשדה `GEMINI_API_KEY` בקובץ `.env`

**מגבלות חינמי:** 15 בקשות בדקה, מספיק לשימוש רגיל.

## הרצה

```bash
npm start
```

בהרצה הראשונה יופיע **קוד QR** בטרמינל.

**סרוק אותו עם WhatsApp** שלך (הגדרות → WhatsApp Web).

לאחר הסריקה תופיע ההודעה:
```
✓ שולי מוכנה! הבוט מחובר ל-WhatsApp
```

**בהרצות הבאות** - לא צריך לסרוק שוב (הסשן נשמר).

## שימוש

הוסף את מספר הטלפון של הבוט לקבוצת ווטסאפ.

כדי להפעיל את שולי, ציין את שמה בהודעה:

### רשימת קניות
```
שולי תוסיפי חלב לרשימה
שולי הוסיפי: ביצים, לחם, גבינה
שולי תמחקי חלב מהרשימה
שולי מה יש ברשימת הקניות?
```

### משימות
```
שולי תוסיפי משימה: לתקן את הברז
שולי תוסיפי משימה לקנות מתנה לדוד - שויך ליוסי
שולי סמני כבוצע - ברז
שולי מה המשימות הפתוחות?
```

### משמרות עובדים
```
שולי שימי את דוד ביום ראשון מ-8 עד 16
שולי הוסיפי משמרת לשרה ב-2024-06-20
שולי מה המשמרות השבוע?
שולי מתי עובד דוד?
```

### נוכחות
```
שולי דוד נכנס
שולי כניסה - יוסי
שולי שרה יוצאת
שולי יציאה - יוסי
שולי מה הנוכחות היום?
שולי מתי נכנס דוד?
```

### בקשות רפואיות
```
שולי יש לי תור לרופא ב-20/6
שולי צריך להגיש טופס 17 לקופת חולים
שולי מה הבקשות הרפואיות הפתוחות?
```

## פתרון בעיות - Windows

### Chromium לא נמצא

אם מופיעה שגיאה שקשורה ל-Chrome/Chromium:

1. פתח את קובץ `.env`
2. הוסף את הנתיב לכרום שלך:
   ```
   PUPPETEER_EXECUTABLE_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
   ```

### שגיאת בנייה ב-better-sqlite3

```
npm install --global node-gyp
npm install
```

אם עדיין לא עובד, ודא שכלי הבנייה של Windows מותקנים (ראה דרישות מוקדמות).

### הבוט מתנתק

הפעל מחדש עם `npm start`. אם זה קורה לעתים קרובות, ודא שהטלפון מחובר לאינטרנט ו-WhatsApp Web מאוחסן.
